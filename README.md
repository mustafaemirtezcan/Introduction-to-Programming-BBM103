# 🧑‍💻Introduction to Programming - BBM103

My first Python assignments. Every folder has the assignment PDF, sample input/output files and my solution.

- **A2 - Sudoku:** solves a 9x9 sudoku by repeatedly filling cells that have only one option, and writes out each step.
- **A3 - Board Game:** a number-grid game played turn by turn in the terminal, where picking a cell clears its matching neighbors.
- **A4 - Blind Valley:** a tile-placement puzzle with row and column limits.

Run any of them with `python <file>.py <input> <output>`.
